# SAVEONY Mobile

SAVEONY is an Expo mobile app for personal finance management.

## Open it on a phone

1. Start the mobile workflow in Replit.
2. Open **Preview on your phone** from the Replit preview controls.
3. Scan the QR code with Expo Go on Android, or with the Camera app on iPhone.
4. Keep Expo Go open while the app loads so the development bundle can finish downloading.

The QR code must come from the current Replit mobile preview. Do not reuse an old QR code after restarting the workflow.

## If Expo Go stays on “Loading”

- Close the old preview in Expo Go and scan the newest QR code again.
- Make sure Expo Go is signed in if it asks for sign-in.
- If Expo Go says the project belongs to another account, sign out of Expo Go and scan again from the Replit preview.

## Project notes

This ZIP is the source project for Expo Go development. It is not an installable Android APK or iOS IPA. The app uses the shared API server and Clerk configuration supplied by the Replit project.
